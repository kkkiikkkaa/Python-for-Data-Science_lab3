# Python-for-Data-Science_lab3

## Опис
У цій лабораторній роботі реалізовано програму на Python з використанням бібліотеки NumPy, яку можна запускати в локальному Docker-контейнері.

Програма:
- створює одновимірний масив з 200 випадкових чисел від -100 до 100;
- за допомогою маски відфільтровує всі додатні числа;
- замінює всі від’ємні значення на нулі;
- обчислює середнє значення отриманого масиву.

## Використані інструменти
- Python
- NumPy
- Docker

### Збірка контейнера
